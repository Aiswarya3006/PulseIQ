# PulseIQ — Five CEO Workforce Questions

1. How has total workforce headcount changed month by month?
2. Which department has the largest headcount in the latest available month?
3. How many hires occurred during the selected reporting period?
4. How many employee exits occurred during the selected reporting period?
5. How is the current workforce distributed across location tiers and work modes?

## Dashboard guidance

- Use the department and date filters to investigate workforce trends.
- Headcount, hires, exits, and attrition use time-based metric views.
- Location tier and work mode represent the current workforce snapshot.
- Confirm metric definitions before using values for executive decisions.
