# PulseIQ - Data Analytics Project

## Project Overview

PulseIQ is an end-to-end data analytics project focused on workforce analytics, financial analytics, data engineering, data quality validation, business intelligence and executive reporting.

The project includes ETL pipelines, data warehouse validation, metric development, interactive dashboards and business insights across multiple phases.

## Project Phases

### Phase 1 - Data Engineering and Analytics (Tasks 1-5)

- Task 1: ETL Pipeline
- Task 2: Data Warehouse and ER Validation
- Task 3: Data Quality Checks
- Task 4: Business Metric Layer
- Task 5: Executive Dashboard

### Phase 2 - Workforce Analytics (Tasks 6-10)

- Task 6: Attendance and Leave Analysis
- Task 7: Employee Attrition Analytics
- Task 8: Team Productivity Analysis
- Task 9: Payroll Cost Dashboard
- Task 10: Budget and KPI Dashboard

### Phase 3 - Business and Financial Analytics (Tasks 11-15)

- Task 11: Finance Analytics and Profit & Loss Analysis
- Task 12: Receivables and Cash Flow Analysis
- Task 13: Cross-Department Impact Analysis
- Task 14: AI Signals and Anomaly Analysis
- Task 15: Executive Company Health Scorecard

## Running the Project

1. Clone the repository:

   git clone https://github.com/Aiswarya3006/PulseIQ.git

2. Open the project folder.

3. Create and activate a Python virtual environment.

4. Install dependencies:

   pip install -r requirements.txt

5. Configure the required database connections.

6. Run the Streamlit application:

   streamlit run app.py
